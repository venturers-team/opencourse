---
title: setState 한 걸음
summary: setState를 부르면 build가 다시 실행되어 화면이 다시 그려진다
---

4.1에서 숙제가 하나 남았어요. 값을 바꾸는 것만으로는 부족하고, 화면도 다시 그려야 한다는 것이었죠. Flutter는 이 두 가지를 한 번에 해 주는 방법을 준비해 두었어요. 이름은 setState예요.

그 전에 build부터 만나 볼게요. 모든 위젯에는 build라는 함수가 있어요. 함수는 이름을 붙여 둔 일 묶음이에요. 이름을 부르면 그 일이 실행돼요. build는 "내 모습을 그려 줘"라고 부탁하면 실행되는 그리기 함수예요. 우리가 지금까지 본 화면은 전부 build가 그린 결과였어요.

이제 핵심 문장이에요. setState를 부르면 상태가 바뀌고, Flutter가 build를 다시 실행해서 바뀐 값으로 화면을 다시 그려요. 이 한 문장이 이번 챕터의 심장이에요. 값 바꾸기와 다시 그리기, 두 가지 숙제가 이 한 줄로 풀려요.

흐름을 그림으로 보면 이래요. 손가락이 버튼을 탭해요. 그러면 setState가 불려요. Flutter가 build를 다시 실행해요. 새 화면이 나타나요.

![](media:fig-01)

코드에서는 이렇게 생겼어요.

```dart
int count = 0;

setState(() {
  count = count + 1;
});
```

count라는 상태 변수를 만들고, setState 안에서 1을 더해요. 그러면 Flutter가 알아서 화면을 다시 그려요.

외울 것은 두 이름뿐이에요. 상태 변수, 그리고 setState. 코드는 AI가 써 줘요. 우리는 받은 코드에 이 흐름이 들어 있는지 확인하면 돼요. 상태 변수가 있는지, 값을 바꾸는 자리가 setState 안인지. 그것만 보면 충분해요.
