# 인프라 연결 절차 (구현 계획 9단계)

코드 쪽 준비는 끝나 있다 — R2 백엔드(`R2MediaBackend`)·빌드 실패 메일 잡·keep-alive 크론·월별 빌드 지표(`pnpm ops builds`)가 전부 환경 변수/저장소 변수만 기다린다. 아래는 사용자와 함께 하는 계정 작업의 정확한 순서다. 전부 venturers.team@gmail.com 명의.

## 1. GitHub 공개 저장소

```bash
gh auth login              # 계정 확인
gh repo create opencourse --public --source . --push
```

푸시 직후 CI가 돌아야 한다 (typecheck → build → test → format → board:check → E2E).

## 2. Cloudflare Pages

대시보드 → Workers & Pages → Pages → Connect to Git → 위 저장소 선택.

| 설정 | 값 |
| --- | --- |
| 빌드 명령 | `pnpm install --frozen-lockfile && pnpm -r build` |
| 출력 디렉터리 | `apps/site/out` |
| 환경 변수 | `NODE_VERSION=22`, `OPENCOURSE_SITE_ORIGIN=https://<프로젝트>.pages.dev` |

확인: 푸시 → 자동 빌드 → 고정 교재가 pages.dev 주소에서 열린다 (9단계 증명 1).

## 3. Cloudflare R2

1. R2 → 버킷 생성 (`opencourse-media`) → **공개 접근(Public Development URL 또는 커스텀 도메인)** 켜기
2. 로컬에 wrangler 로그인: `npx wrangler login`
3. 생성 환경 변수 (로컬 `.env` 또는 셸 — 커밋 금지):

```bash
export OPENCOURSE_R2_BUCKET=opencourse-media
export OPENCOURSE_R2_PUBLIC_URL=https://<공개 도메인>
```

이후 S11 업로드는 `mediaBackendFromEnv()`가 자동으로 R2를 고른다. 확인: 파일 하나 올려 R2 주소로 응답 (9단계 증명 2 — `verify()`가 HEAD로 자동 확인).

## 4. 빌드 실패 메일

1. Gmail 앱 비밀번호 발급 (Google 계정 → 보안 → 2단계 인증 → 앱 비밀번호)
2. GitHub 저장소 → Settings → Secrets and variables → Actions:
   - 시크릿 `MAIL_USERNAME` = venturers.team@gmail.com, `MAIL_APP_PASSWORD` = 앱 비밀번호
   - 변수 `NOTIFY_EMAIL` = 받을 주소
3. 확인: 빌드를 고의로 깨뜨려 메일 수신 (9단계 증명 3)

## 5. 월별 빌드 지표

Cloudflare 대시보드 → My Profile → API Tokens → Pages Read 권한 토큰 발급.

```bash
export CLOUDFLARE_API_TOKEN=... CLOUDFLARE_ACCOUNT_ID=... CLOUDFLARE_PAGES_PROJECT=opencourse
pnpm ops builds   # → "이번 달 빌드 N / 500회"
```

## 6. 열쇠 백업과 복구 절차 (README의 "착수 전에 정할 것")

**백업 대상** — 이것들이 전부다. 하나라도 빠지면 복구가 안 된다:

| 열쇠 | 어디서 나왔나 | 잃으면 |
| --- | --- | --- |
| GitHub 계정 + 2FA 복구 코드 | github.com | 저장소·CI 제어 상실 |
| Cloudflare API 토큰 | 대시보드 API Tokens | 지표 조회 불가 (재발급 가능) |
| Cloudflare 계정 로그인 | cloudflare.com | Pages·R2 제어 상실 |
| Gmail 앱 비밀번호 | Google 보안 | 실패 메일 정지 (재발급 가능) |
| Supabase DB 비밀번호·service_role 키 | 프로젝트 생성 시 (10단계) | 챗봇 서버 제어 상실 |
| OpenRouter API 키 | openrouter.ai (10단계) | 챗봇 정지 (재발급 가능) |

**백업 방법**: 비밀번호 관리자(권장: Bitwarden 무료)에 `오픈코스` 폴더를 만들어 위 표의 모든 항목 + 이 문서 링크를 저장한다. 관리자의 마스터 비밀번호와 2FA 복구 코드는 **종이로 한 부** 물리적으로 보관한다. 기기 안에만 있는 백업은 백업이 아니다.

**복구 절차** (새 기기 기준):
1. 비밀번호 관리자 로그인 → `오픈코스` 폴더 확인
2. `git clone` → `pnpm install` → `pnpm test` (코드와 콘텐츠는 저장소가 전부다 — docs/03)
3. `gh auth login`, `npx wrangler login`, 위 5절의 환경 변수 복원
4. `pnpm e2e`와 `pnpm ops builds`가 돌면 복구 완료

**복구 리허설** (9단계 증명 4): 깨끗한 임시 폴더에서 위 절차를 백업만 보고 그대로 따라 해 보고, 걸린 시간과 막힌 지점을 이 문서에 추가한다.
