# 공개 사이트 완결판 IA

> [화면 구조](04-화면-구조.md)의 화면 1~5를 **디자인 입력 수준**으로 확장한 문서다. 사용자가 이 문서 끝의 핸드오프 프롬프트를 Claude Design으로 가져가 디자인 시스템과 화면 시안을 만들고, 그 결과를 구현 계획 7단계가 `packages/ui`로 옮긴다. 여기의 컴포넌트·상태 목록이 곧 디자인 시스템이 다뤄야 할 부품의 전부다. 데이터 필드는 [콘텐츠 계약 스키마](11-콘텐츠-계약-스키마.md)를 가리킨다.

---

## 페이지 목록과 주소

| 주소 | 페이지 | 비고 |
| --- | --- | --- |
| `/` | 교재 목록 | 첫 화면 |
| `/{교재슬러그}` | 교재 상세와 목차 | |
| `/{교재슬러그}/{챕터슬러그}` | 섹션(챕터) 페이지 | 소단원들을 한 페이지로 이어 붙임 |
| 없는·숨김·초안 주소 | 접근 불가 안내 | 셋을 구분하지 않는 같은 화면 |
| `/privacy` | 개인정보 처리방침 | 챗봇 출시(10단계)와 함께. 정적 문서 페이지 |
| — (오버레이) | 부유형 챗봇 패널 | 섹션 페이지 위에 얹힘, 주소 없음 |
| `/sitemap.xml` `/robots.txt` | 수집 정보 | 발행 교재만 |

**전역 구조**: 상단 헤더(로고 = 홈 링크, 그 외 최소), 하단 푸터(처리방침 링크, 저장소 링크, 저작권 표기). 로그인 UI는 전역에 없다 — 로그인은 챗봇 패널 안에서만 일어난다. 라이트·다크 지원 여부는 디자인 시스템에서 결정한다.

## 페이지별 설계

### 1. 교재 목록 `/`

**한 줄 목적**: 발행된 교재 중 읽을 것을 고른다.

| 구역 | 내용 | 데이터 출처 |
| --- | --- | --- |
| 인트로 | 서비스 한 줄 소개 | 고정 문구 |
| 컨트롤 바 | 검색 입력, 대상 학습자 필터, 난이도 필터, 정렬(발행일↔제목), 조건 초기화 | 클라이언트 사이드 |
| 교재 그리드 | 교재 카드 목록 | `course.json` (status=published만) |
| 빈 상태 | 발행 교재 0건 안내 / 필터 결과 0건 안내 (다른 문구) | |

**교재 카드**: 제목, 한 줄 설명(`summary`), 대상(`audience`), 난이도 배지(`difficulty`), 섹션 수(`chapters.length`), 예상 학습 시간(`estimated_minutes`), 마지막 발행일. 카드 전체가 링크.

### 2. 교재 상세 `/{slug}`

**한 줄 목적**: 전체 구조를 가늠하고 읽기 시작한다.

| 구역 | 내용 | 데이터 출처 |
| --- | --- | --- |
| 교재 헤더 | 제목, 학습 목표 목록, 대상, 난이도, 예상 시간 | `course.json` |
| 개요 영상 | 교재 개요 영상 플레이어 (아래 플레이어 명세) | 교재 media |
| 시작 버튼 | "첫 섹션부터 시작" — 페이지의 주 행동 | |
| 목차 | 챕터 목록: 번호, 제목, 한 줄 요약, 예상 시간. 각 항목이 링크 | `course.json.chapters` |
| 출처 | 참고 자료 목록 (펼침/접힘): 제목, 발행처, 링크, 사용 조건 | `source-map.json` |

### 3. 섹션 페이지 `/{slug}/{chapter}`

**한 줄 목적**: 실제로 읽는다. 이 사이트에서 체류가 가장 긴 화면.

| 구역 | 내용 | 데이터 출처 |
| --- | --- | --- |
| 섹션 헤더 | 교재명(상세로 링크), 챕터 번호·제목, 진행 위치 (N/전체) | |
| 섹션 개요 영상 | 본문 앞 플레이어 | `media.json.video` |
| 본문 | 소단원들을 순서대로 이어 붙인 MDX 렌더. 소제목(h2=소단원, h3=본문 소제목), 산문, 목록, 표, 인용, 코드 블록, 인포그래픽 | `NN.mdx` |
| 인포그래픽 프레임 | 이미지 + 대체 설명, 확대 보기 | `media.json.items` |
| 본문 내 목차 | 소제목 목록, 현재 위치 표시 (넓은 화면: 사이드 고정 / 좁은 화면: 접힘 버튼) | |
| 하단 내비 | 이전 섹션 / 다음 섹션 (제목 표시), 전체 목차 열기 | |
| 유틸리티 | 맨 위로 버튼 | |
| 챗봇 런처 | 화면 구석 고정 버튼 → 패널 오버레이 | |

**영상 플레이어 명세** (교재·섹션 공용): 파일이 아니라 브라우저 조립(Remotion). 상태 = `준비 중(로딩 표시와 안내 문구) / 재생 / 일시 정지 / 종료(다시 보기) / 오류(안내와 새로고침)`. 컨트롤 = 재생·정지, 진행 바, 자막 켬·끔, 소리. **다운로드·전체화면 저장 수단 없음.** 자막은 기본 켬.

### 4. 접근 불가 안내

없는 주소·숨김·초안 **셋이 구분되지 않는** 하나의 화면. 안내 문장 + "교재 목록으로" 버튼 하나. 존재 여부를 짐작하게 하는 어떤 차이도 없어야 한다(응답 코드 포함).

### 5. 부유형 챗봇 패널 (오버레이)

기본 닫힘. 열기 전에는 어떤 서버 호출도 없다. 상태 기계:

| 상태 | 화면 | 전이 |
| --- | --- | --- |
| 닫힘 | 런처 버튼만 | 클릭 → 열림 |
| 비로그인 | "질문 횟수를 세기 위한 로그인입니다. 로그인 없이도 교재는 전부 읽을 수 있어요" + Google 로그인 버튼 + "대화는 평가에 쓰이지 않습니다" 고정 문구 | 로그인 → 대기 |
| 대기 | 입력창, 남은 오늘 질문 수, 대화 기록, 대화 지우기 | 전송 → 응답 중 |
| 응답 중 | 진행 표시, 입력 잠금 | 완료 → 대기 |
| 한도 소진 | "오늘 한도를 다 썼어요. 내일 다시" + 입력 비활성 | 자정 후 → 대기 |
| 장애 | "지금은 챗봇을 쓸 수 없는 상태예요" — 질문 탓이 아님을 명시 | 재시도 |

패널은 읽던 본문을 가리지 않는 크기(사이드 시트 형태 권장, 모바일은 하단 시트).

## 컴포넌트 인벤토리

디자인 시스템이 정의해야 할 부품의 전체 목록이다.

**전역**: 헤더 / 푸터 / 링크·버튼(주·보조·텍스트) / 배지(난이도, 대상) / 테마 토큰(색·타이포·간격·모서리·그림자)

**목록**: 교재 카드 / 검색 입력 / 필터 셀렉트 / 정렬 셀렉트 / 조건 초기화 / 빈 상태 일러스트·문구

**상세·본문**: 교재 헤더 블록 / 학습 목표 목록 / 목차 리스트(챕터 행) / 시작 버튼 / 출처 아코디언 / 본문 타이포그래피(제목 계층, 산문, 목록, 표, 인용, 코드 블록) / 인포그래픽 프레임(캡션·대체 설명·확대) / 본문 내 목차(TOC) / 이전·다음 내비 / 진행 위치 표시 / 맨 위로 버튼

**영상**: 플레이어 프레임 / 재생 컨트롤 / 진행 바 / 자막 표시 영역 / 준비 중·오류 상태

**챗봇**: 런처 버튼 / 패널 셸(사이드·하단 시트) / 메시지 말풍선(질문·답변) / 입력창과 전송 / 남은 횟수 표시 / 로그인 안내 블록 / 한도·장애 안내 블록

**공통 상태**: 로딩 스켈레톤 / 빈 상태 / 오류 안내 / 포커스 링

## 요구 조건 (디자인이 지켜야 할 것)

- **접근성이 1차 출시 범위다**: 모든 조작이 키보드만으로 가능, 보이는 포커스, 본문 대비 WCAG AA, 상태·오류를 색만으로 전달하지 않음, 인포그래픽 대체 설명과 영상 자막이 언제나 표시 가능
- **한국어 본문 최적화**: 본문 줄 길이 65자 안팎, 한글 가독 우선 서체, 코드 블록은 고정폭
- 모바일(360px)부터 데스크톱까지 반응형. 표·코드 블록은 자체 가로 스크롤
- 학습을 방해하는 요소 금지: 자동 재생 없음, 팝업 없음, 챗봇은 닫힘이 기본
- 정적 사이트다: 검색·필터도 클라이언트 사이드, 서버 의존 UI 없음(챗봇 패널 제외)

## Claude Design 핸드오프 프롬프트

아래를 복사해 Claude Design에 붙여 넣는다. `[ ]` 자리는 사용자가 채운다.

```
한국어 AI 생성 웹 교재 서비스 "오픈코스"의 공개 사이트를 디자인해 줘.

제품 한 줄: 주제를 입력하면 AI가 웹 교재를 만들고, 검수를 통과한 것만 발행되는 서비스.
독자: 그 주제를 처음 배우는 한국 대학생. 로그인 없이 읽는다.
무드: [ 원하는 무드 키워드 2~3개. 예: 차분한, 교과서적인, 신뢰감 ]
참고하고 싶은 레퍼런스: [ 있으면 링크나 이름 ]

만들 화면 4종 + 오버레이 1종:
1. 교재 목록(홈): 카드 그리드, 검색·대상·난이도 필터, 정렬, 빈 상태
2. 교재 상세: 제목·학습 목표·난이도·예상 시간, 개요 영상 플레이어, "첫 섹션부터 시작" 주 버튼, 챕터 목차, 출처 아코디언
3. 섹션(본문) 페이지: 개요 영상, 긴 한국어 본문(제목 계층·목록·표·인용·코드 블록), 인포그래픽 프레임(캡션·확대), 사이드 목차, 이전·다음 내비, 진행 위치
4. 접근 불가 안내: 안내 문장과 목록으로 가는 버튼 하나뿐인 화면
5. 부유형 챗봇 패널(사이드 시트): 닫힘 런처 / 로그인 안내("질문 횟수를 세기 위한 로그인, 읽기는 로그인 불필요", "대화는 평가에 쓰이지 않습니다") / 대화·입력·남은 질문 수 / 한도 소진 / 장애 안내 — 상태별로.

디자인 시스템으로 함께 정의해 줘:
- 색 토큰(라이트·다크), 한국어 본문에 맞는 타이포 스케일(본문 줄 길이 65자 안팎), 간격·모서리·그림자 토큰
- 버튼(주·보조·텍스트), 배지, 카드, 입력·셀렉트, 아코디언, 로딩 스켈레톤, 빈 상태, 오류 안내, 포커스 링
- 영상 플레이어 프레임(재생·진행 바·자막 켬끔·"준비 중" 상태 — 다운로드 버튼은 없음)

지켜야 할 것: WCAG AA 대비, 보이는 키보드 포커스, 상태를 색만으로 전달하지 않기,
모바일 360px부터 반응형, 자동 재생·팝업 없음, 학습 방해 요소 없음.
```

디자인 결과가 나오면: 토큰 값과 컴포넌트 시안을 구현 계획 7단계에서 `packages/ui`로 옮기고, 스타일 가이드 페이지로 전 컴포넌트를 두 테마로 렌더해 사용자 승인을 받는다.
