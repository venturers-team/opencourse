## 폴더

```
docs/                  설계 문서
content/
  courses/<슬러그>/    교재 한 권. 지금은 비어 있다
  standards/           모든 교재가 함께 쓰는 검수 기준
ops/runs/              생성 작업 요약 기록
```

`content/standards/`의 다섯 문서는 **검수가 판정에 쓰는 실제 기준**이다. 설계 문서가 아니라 제품이 읽는 입력이다. [기준 문서 개요](content/standards/README.md)에 어느 검수가 어느 문서를 읽는지 적혀 있다.

## 전신과의 관계

이 프로젝트의 전신은 **Wikidox Agent**다. 2026년 8월 23일에 이름을 오픈코스로 바꾸고 새로 시작했다. 설계 문서에 Wikidox라는 이름이 나오면 이 제품의 옛 이름이다.

v1 코드는 `~/Projects/5-Archives/Wikidox Agent/wikidox`에 보존되어 있다. v2는 v1을 고치는 것이 아니라 **다시 짓는 것**이다.

이유는 두 가지다. v1은 교재를 네 군데에 나누어 쌓고 있어 같은 파일이 두 자리에서 내용이 갈라진 곳이 있다. 그리고 저장 계층의 전제였던 사업자가 무료 제공을 중단해 저장과 배포 구성을 통째로 다시 잡아야 했다. 자세한 것은 [아키텍처 결정](docs/03-아키텍처-결정.md)에 있다.

v1의 자산 중 가져올 것은 생성 파이프라인의 단계 구성과 검수 스크립트의 판정 로직이다. **폴더 배치와 상태 관리는 가져오지 않는다.**
