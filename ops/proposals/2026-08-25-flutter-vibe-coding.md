# 실전 교재 목차 제안 (11단계 · 파이프라인 S3 — 승인 대기)

11단계 인수 시험("진짜 교재 한 권 완주")의 S1~S3 준비물이다. **승인이 있어야 S4 이후로 진행한다** (docs/10). 주제가 마음에 안 들면 바꿔서 다시 제안한다.

## 제안 개요

| 항목 | 값 |
| --- | --- |
| 제목 | 바이브 코딩으로 배우는 Flutter 첫걸음 |
| 주제 | AI 코딩 도구와 대화하며 만드는 첫 Flutter 앱 |
| 대상 | 프로그래밍이 처음인 비전공 대학생 |
| 난이도 | beginner (입문) |
| 언어 | ko |
| 분량 | 챕터 5 · 소단원 14 · 예상 학습 5시간 안팎 |

디자인 목업이 이 주제(9챕터 판)로 그려져 있어 화면 검증과 자연스럽게 맞물린다. 실전 완주 비용(챕터마다 TTS·재전사·인포그래픽·영상 조립)을 생각해 **5챕터로 압축**했다 — 완주가 목적이지 대작이 목적이 아니다. 잘 돌면 증보는 언제든 가능하다.

## 학습 목표 (course.json `learning_outcomes`)

1. 위젯 트리로 화면 구조를 읽고 그릴 수 있다
2. AI 도구에게 원하는 화면을 구조로 설명하는 프롬프트를 쓸 수 있다
3. 받은 코드를 트리와 대조해 읽고 작은 수정을 직접 할 수 있다
4. setState로 사용자 입력에 반응하는 화면을 만들 수 있다

| # | 챕터 (id) | 소단원 | 챕터가 끝나면 |

| 2 | 첫 프로젝트 만들기 (`02-first-project`) | ① Flutter 프로젝트의 생김새 ② AI에게 첫 화면 부탁하기 ③ 실행하고 확인하기 | 빈 앱을 실행해 본다 |
| 3 | 위젯 트리 이해하기 (`03-widget-tree`) | ① 위젯이 뭐예요 ② 트리 읽는 법 ③ 트리 고쳐 그리기 | 코드를 그림으로 읽는다 |
| 4 | 상태로 움직이는 화면 (`04-state`) | ① 상태가 뭐예요 ② setState 한 걸음 ③ 실습 — 숫자 세기 버튼 | 입력에 반응하는 앱을 만든다 |
