[챕터 3 확정 요약] 위젯=화면의 부품("모든 것이 위젯"). 품는 쪽=부모, 안기는 쪽=자식, 쌓인 전체=트리(뿌리 MaterialApp, 잎 Text). 읽는 규칙: 들여쓰기가 곧 트리 — 안으로 들어갈수록 자식, child: 다음이 자식. 트리를 읽으면 실행 전에 화면을 예상하고 구조로 부탁할 수 있음. 화면 수정 원칙: 트리 먼저 고쳐 그린다 — 자식이 둘이 되면 사이에 Column(자식들을 세로로 늘어놓는 위젯) 필요. 확인 요령: Column 아래 한 단 더 들어간 줄이 둘인지. 챕터 습관: 그림 먼저 → 부탁 → 코드 확인. 버튼 위젯 이름 ElevatedButton은 그림에만 등장, 본문에서는 '버튼'으로 지칭.
