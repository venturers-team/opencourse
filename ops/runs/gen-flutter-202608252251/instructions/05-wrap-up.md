## 모든 챕터 공통 (스타일 v1 + 초보자 기준)

- 해요체. 문장은 짧게, 한 문장에 하나의 생각만. 과장·감탄 남용 금지
- 독자: 이 주제를 이번 학기에 처음 배우는 비전공 대학생. **모르는 말이 나와도 검색하지 않는다** — 전공 용어는 나오는 자리에서 바로 풀어 쓴다
- 용어 통일: 챕터(단원 X), 소단원, 학습자, 도우미
- 소단원 900자 안팎, 챕터 합계 3000자 이하 (기계 검사가 강제)
- "뒤에서 다루겠다"류 약속 어구 금지 (ST01), 확인 못 한 사실은 그대로 적기 (기계 검사가 잡는다)
- 미디어는 식별자로만: `![](media:fig-01)` 한 줄. URL 직접 기입 금지
- 출처 인용은 source-map의 src-001~003만. 새 출처는 등록 먼저
- 문맥은 이 지시문 + 앞 챕터 확정 요약만 사용. 뒤 챕터 내용을 미리 언급하지 않는다
